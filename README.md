1. What is the purpose of the try and catch blocks?

The try block is used for code that may have errors, and the catch block is used to handle those errors and show a message.

2. Explain the difference between throw and throws.

throw is used when we want to raise an exception, while throws is written in a method declaration to show that an exception may occur.

3. What is the purpose of the finally block?

The finally block runs at the end, whether an error happens or not. In this program, it is used to close the Scanner.

4. Why is a custom exception useful in this application?

A custom exception helps us show the right error message when a student enters invalid information, such as an age below 18 or more than five subjects.
